# 스프링 개발자를 위한 파이썬 가이드

이 프로젝트의 코드를 스프링 부트 기준으로 읽기 위한 대응표입니다. 모르는 문법이 나오면 여기서 찾으세요.

## 1. 한눈에 보는 대응표

### 프로젝트·빌드
| 파이썬 | 스프링 |
|---|---|
| `pyproject.toml` | `build.gradle` / `pom.xml` (의존성, 도구 설정) |
| `requirements.txt` (챗봇) | 의존성 목록만 적은 간단한 버전 |
| `.venv/` (가상환경) | 프로젝트별 라이브러리 격리. Gradle은 기본 제공이라 따로 안 만들 뿐 |
| `pip install` | Gradle이 의존성을 내려받는 것 |
| `uvicorn` | 내장 Tomcat (서버 실행기) |
| `src/text_to_sql/` | `src/main/java/.../` |
| `tests/` | `src/test/java/` |
| `__init__.py` | 폴더를 패키지로 인식시키는 빈 파일 (자바는 폴더 자체가 패키지) |

### 문법
| 파이썬 | 자바 |
|---|---|
| 들여쓰기(4칸) | 중괄호 `{ }` |
| `self` | `this` (파이썬은 메서드의 **첫 파라미터에 직접 적음**) |
| `def f(x: str) -> int:` | `int f(String x)` (타입 위치가 반대) |
| `dict[str, int]` | `Map<String, Integer>` |
| `list[str]` | `List<String>` |
| `f"안녕 {name}"` | `"안녕 " + name` / `String.format` |
| `None` | `null` |
| `import json` / `from a import b` | `import` |
| `@dataclass` | Lombok `@Data` 또는 Java `record` |
| `Protocol` | `interface` (단, `implements` 없이 **모양만 맞으면** 인정) |
| `raise X(...)` | `throw new X(...)` |
| `raise X(...) from err` | `new X(msg, cause)` (원인 예외 연결) |
| `try / except` | `try / catch` |
| `with open(...) as f:` | `try-with-resources` |
| `class A(Exception)` | `class A extends RuntimeException` |

**중요한 차이 두 가지**
- 파이썬에는 **checked exception이 없습니다.** `throws` 선언도 없고, 어떤 함수든 예외를 던질 수 있습니다.
- 타입 표시(`str`, `int`)는 **실행할 때 강제되지 않습니다.** 대신 `mypy`가 컴파일러처럼 미리 검사해 줍니다.

### 도구
| 파이썬 | 스프링 |
|---|---|
| `pytest` | JUnit5 |
| `assert a == b` | `assertEquals(b, a)` |
| `pytest.raises(X)` | `assertThrows(X.class, ...)` |
| `tmp_path` | `@TempDir` |
| `test_`로 시작하는 함수 | `@Test` 메서드 (이름 규칙으로 자동 인식) |
| `mypy` | `javac`의 타입 검사 |
| `ruff` | Checkstyle / Spotless (스타일·import 정리) |
| `pydantic` (`BaseModel`) | DTO + Bean Validation (`@Valid`, `@NotNull`) |

### FastAPI (웹 프레임워크)
| FastAPI | 스프링 |
|---|---|
| `@app.post("/api/ask")` | `@PostMapping("/api/ask")` |
| 요청용 `BaseModel` 클래스 | `@RequestBody` DTO |
| `Depends(auth.get_current_user)` | `@Autowired` 주입 / Security 필터 결과를 파라미터로 받는 것 |
| `HTTPException(status_code=400)` | `ResponseStatusException` |
| `lifespan` | `@PostConstruct` / `ApplicationRunner` (서버 시작 시 1회 실행) |
| `app.mount("/static", ...)` | `static/` 리소스 핸들러 |

## 2. 이 프로젝트의 폴더 = 스프링 계층

```
src/text_to_sql/
 ├─ api/          ← @RestController + DTO + 예외 처리(@ControllerAdvice)
 ├─ services/     ← @Service       (업무 로직: SQL 조립, 검증, LLM 호출)
 ├─ repositories/ ← @Repository    (데이터 읽기. 여기서는 DB가 아니라 JSON 파일)
 ├─ domain/       ← 도메인 모델/VO (메타데이터, 의도 객체)
 ├─ errors.py     ← 예외 클래스 모음
 └─ config.py     ← application.yml + @ConfigurationProperties
metadata/*.json   ← src/main/resources 의 설정 파일
tests/            ← src/test/java
```

요청이 흐르는 길은 스프링과 같습니다.

```
HTTP 요청 → api(Controller) → services(Service) → repositories(Repository) → 메타데이터 JSON
```

## 3. 지금 구현한 코드 읽기 (`repositories/metadata_repository.py`)

| 코드 | 스프링으로 치면 |
|---|---|
| `@dataclass class SiteProfile` | 필드 3개짜리 VO. Lombok `@Data`로 생성자·getter 자동 생성 |
| `types: dict[str, int]` | `Map<String, Integer> types` |
| `def find_typeid(self, ...)` | 인스턴스 메서드 |
| `raise UnsupportedQuestionError(...) from err` | `throw new UnsupportedQuestionException(msg, err)` |
| `def load_site_profile(path)` | `class` 밖에 있는 **독립 함수**. 자바라면 정적 팩토리 메서드(`SiteProfile.load(path)`) |
| `with open(...)` | 파일을 열고 자동으로 닫음 |
| `json.load(f)` | Jackson `objectMapper.readValue(...)`. 결과는 `Map` |
| `data["types"]` | `map.get("types")`. 없으면 `KeyError` (자바는 `null`) |

**자바와 다른 점:** 파이썬은 클래스 없이 함수만 만들어도 됩니다. 그래서 `load_site_profile`이 클래스 안이 아니라 파일 맨 아래에 있습니다.

## 4. 기존 챗봇(`C:\side_chatbot`)도 같은 틀로 읽기

| 파일 | 스프링으로 치면 |
|---|---|
| `app/main.py` | `@RestController` + DTO + 시작 설정이 **한 클래스에 다 들어 있는 형태** |
| `app/rag.py` | `@Service` (임베딩, 검색, OpenAI 호출) |
| `app/db.py` | `@Repository` (DB 접근) |
| `app/auth.py` | Spring Security (비밀번호 해시, JWT) |
| `static/*.html` | 프론트 (정적 파일) |

챗봇은 계층 분리가 느슨한 구조(Controller 하나에 다 모임)이고, 이 프로젝트(`text-to-sql`)는 계층을 나눈 구조입니다. 그래서 나중에 붙일 때는 챗봇의 `main.py`에 **엔드포인트 하나만 추가**하고, 나머지는 `text_to_sql` 패키지를 그대로 가져다 쓰면 됩니다.

## 5. 읽는 요령
- 파이썬은 **위에서 아래로 실행**됩니다. `main`이 필요 없고 함수 정의 순서가 중요하지 않습니다 (호출 시점에만 필요).
- 이름 앞의 `_`(언더스코어)는 "내부용"이라는 관례일 뿐 `private`처럼 강제되지는 않습니다.
- `import`한 이름이 어디서 왔는지는 `from 경로 import 이름`의 **경로**를 보면 됩니다 (`text_to_sql/repositories/metadata_repository.py`).
- 모르는 문법이 나오면 그 줄을 저에게 보여 주세요. 스프링 코드로 바꿔서 설명하겠습니다.
